# Ramp tracking rules (agreed with Sheila)

## Dates
- Closer calendar go-live = date of the first 45-min Discovery call actually held (Close meeting, duration 2700s, completed).
- Ramp month N = 30-day-ish windows counted from go-live (e.g. go-live 10/15 → month 1 is 10/15–11/14), not calendar months.
- Setter promotes: "ascension start" (training/cohort start) and "first self-set closer call" are separate dates. Pre-ramp month 1 starts at the first self-set call.
  - Dave: ascension start 9/8 (first cohort call), first self-set 9/25 (back from travel).
- Pre-ramp clock pauses while the person is away (Quinn's vacation); it resumes on return.

## New hire closer track
- Pre-ramp ~2 weeks: self-guided training + call audit (week 1, from actual start day), mock call with Jay + self-review, setter week.
- Setter week floor: 6 booked/day, 4 live/day (80% show), 20 live calls for the week.
- Ramp month 1: 60 open slots, $100K target, $75K floor (below = out), 12–15% CTC.
  - Watch if Jay-flagged issues are unfixed by the 5th shown call; out if unfixed by the 10th shown call (both tracks).
- Ramp month 2: month 1 ≥ $100K → open path (75 scheduled, $200K, 20% CTC); < $100K → throttled (60 scheduled, $150K, 20% CTC). $95K–$99.9K: flag to Sheila to decide. $150K floor on both paths.
- Ramp month 3: 75 scheduled, $200K and 25% CTC; missing either is a cut.

## Setter promote track
- Same training, call audit, mock call.
- Self-set phase: ~5–6 booked setter calls + 1–2 closer calls daily.
- Pre-ramp month 1: ~20 closer calls, 15% CTC. Pre-ramp month 2: ~40 closer calls, 15% CTC. Below 15% → not ascended.
- After closer calendar go-live: same ramp months 1–3 targets and cuts as new hire closers.

## Sources
- Cash: 2M tracker read API (read-only; never modify that repo). Backup: Sales Tracker 2026.

- Roster inputs: "Roster" tab in the New Hire Tracker sheet. Snapshot saved to this repo each run.
- Call review: track Jay's feedback against the latest rubric; no AI pre-grading for now.
